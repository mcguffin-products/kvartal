# Квартал от McGuffin

Интерактивная презентация продукта «Квартал» со встроенным живым демо.

Сайт: https://mcguffin-products.github.io/kvartal/

- `index.html` — презентация (9 слайдов, RU/EN, светлая/тёмная тема)
- `demo.html` — живое демо, открывается с последнего слайда
- `og.jpg` — картинка превью для мессенджеров

Публикация: GitHub Pages, ветка `main`, корень репозитория. Любой коммит в `main` обновляет сайт по тому же адресу.
